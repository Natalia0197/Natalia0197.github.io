Prólogo

Este portafolio reúne las prácticas desarrolladas a lo largo del curso de Sistemas Operativos, mismas que cuentan con una breve reflexión para demostrar el aprendezaje adquirido a lo largo del curso. A través de cada tema, se exploran los mecanismos fundamentales que permiten a un sistema operativo administrar los recursos de cómputo: desde la creación y comunicación de procesos, pasando por la gestión de memoria y el sistema de archivos, hasta el manejo de señales asíncronas.

El material se basa en el texto Un vistazo a los Sistemas Operativos del M.C. Gabriel Gerónimo C. del Instituto de Computación de la UTM, complementado con la exploración práctica del entorno GNU/Linux. Cada sección documenta lo aprendido, el código desarrollado y reflexiones sobre cómo profundizar en cada tema.

Los temas están organizados de forma progresiva: iniciando con los fundamentos de Linux, avanzando por procesos e hilos, mecanismos de IPC, administración de memoria, arquitectura del sistema de archivos y finalizando con el manejo de señales. Se espera que este portafolio sirva como referencia de consulta y evidencia del aprendizaje adquirido durante el semestre.

Práctica destacada

Práctica · Tema 1 — Introducción a Linux

Mini Bash en C

Implementación de una mini shell en C que reproduce el comportamiento de comandos reales de Linux mediante llamadas al sistema. Se desarrollaron 19 comandos propios incluyendo ls, cd, pwd, stat, find, df, free, uname, who, ip y mac, entre otros.

Lo que aprendí

Este proyecto me permitió aplicar directamente las llamadas al sistema de Linux que el kernel expone al espacio de usuario: stat(), getcwd(), chdir(), readdir(), statvfs() y uname(), entre otras. Trabajé con estructuras reales del sistema como struct stat, struct utsname y struct utmpx, y aprendí a consultar información de red a bajo nivel usando sockets e ioctl(). Implementar find de forma recursiva me ayudó a entender cómo el sistema operativo organiza el árbol de directorios.

Cómo podría mejorarse

Se podría agregar soporte de flags en comandos como ls -la, implementar un historial de comandos con la flecha arriba, y añadir pipes y redirección (|, >) para acercar la shell a cómo funciona bash realmente. También sería valioso manejar señales como SIGINT y SIGTSTP para controlar procesos con Ctrl+C y Ctrl+Z, conectando esta práctica directamente con el tema de señales del curso.
